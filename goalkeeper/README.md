# Goalkeeper — TON Mini-App

Goalkeeper is the TON-focused Mini-App foundation for SandyChainHub.

## Current stage

- Static Mini-App shell
- TON Connect UI starter
- Public TON Connect manifest
- Testnet-first development plan
- No mainnet transaction logic

## Roadmap

1. Verify TON Connect manifest
2. Test wallet connection
3. Add Telegram Mini-App SDK
4. Connect Goalkeeper identity/profile to SandyChainHub
5. Add TON-specific features after the foundation is stable

Never place seed phrases or private keys in this repository.
