# Security Policy

SandyChainHub is a SYSFI testnet community and builder MVP.

## Security priorities
- Never commit private keys, seed phrases, API credentials, or wallet secrets.
- Public contract and wallet addresses may be documented; signing secrets must never be stored in source.
- Testnet-only restrictions must remain explicit in the contract and UI.
- Frontend validation is not a substitute for smart-contract validation.

## Reporting
Use GitHub's private security reporting mechanism when available. Do not disclose exploitable details publicly before a fix is available.
