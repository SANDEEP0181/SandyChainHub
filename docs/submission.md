# Builder submission checklist

Use this checklist when preparing SandyChainHub for an external builder program.

## Project information

- Project: SandyChainHub
- Category: Web3 infrastructure / community tooling
- Status: MVP / testnet
- Repository: https://github.com/SANDEEP0181/SandyChainHub

## Submission package

1. GitHub repository
2. Smart-contract source
3. ABI
4. Test results
5. Testnet contract address after deployment
6. Explorer link after deployment
7. Live frontend/demo URL if available
8. README and architecture documentation
9. Security notes
10. Short demo video/screenshots if requested

## Verify before submitting

Always check the current official program documentation for:

- Supported network and deployment environment
- Current RPC/chain configuration
- Required contract or application format
- Application/submission process
- Deadline
- Reward eligibility and terms
- Required demo links or evidence

Do not assume that deploying a contract automatically qualifies a project for a reward.
